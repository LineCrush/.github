# LineCrush support

Choose the route that matches what you need so the right person sees it.

## Product help and feedback

- Use the [LineCrush contact page](https://www.linecrush.com/contact) for product questions, account help, partnership inquiries, and detailed feedback.
- Join the [LineCrush Discord](https://discord.gg/j5zG6ZZ6NQ) for community help and product discussion.
- Visit [linecrush.com](https://www.linecrush.com) to access the current product.

## Account or billing help

Use the [contact page](https://www.linecrush.com/contact) or email [hello@linecrush.com](mailto:hello@linecrush.com). Include the email address on the LineCrush account and any relevant invoice or receipt identifier.

Never send your password, full card number, security code, session cookie, API token, or other credentials.

## Bugs in this repository

This repository contains the public organization profile and community guidance, not the LineCrush application source. A pull request is welcome for a clear typo, dead link, or accessibility improvement. Product bugs belong in the [contact flow](https://www.linecrush.com/contact) or Discord.

## Security concerns

Follow the private reporting instructions in [`SECURITY.md`](SECURITY.md). Do not report a suspected vulnerability in a public issue, pull request, or community channel.
