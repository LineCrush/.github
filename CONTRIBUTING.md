# Contributing

Thanks for helping improve LineCrush's public GitHub presence.

## What this repository accepts

The product source is private. Contributions to this repository should stay focused on public organization files, such as:

- correcting a typo or broken link;
- improving clarity or accessibility;
- fixing inaccurate public product information; or
- improving the security, support, or community guidance.

Product feature requests, account questions, and application bug reports should go through the [LineCrush contact page](https://www.linecrush.com/contact) or [Discord](https://discord.gg/j5zG6ZZ6NQ).

## Before opening a pull request

1. Keep the change small and limited to the public file that needs it.
2. Verify every changed URL and review the rendered Markdown.
3. Explain what was inaccurate or unclear and why the change fixes it.
4. Do not include secrets, private repository details, customer information, screenshots with personal data, or internal operating instructions.
5. Follow the [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

By submitting a contribution, you confirm that you have the right to provide it and agree that LineCrush may use, modify, and publish it as part of this repository.

For suspected security issues, stop and follow [`SECURITY.md`](SECURITY.md) instead of opening a public pull request.
